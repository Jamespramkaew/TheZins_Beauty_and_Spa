# TheZins Beauty & Spa

เว็บไซต์ร้านสปา แยกเป็น frontend และ backend อยู่ใน repo เดียวกัน (monorepo)

## โครงสร้างโปรเจกต์

```
TheZins_Beauty_and_Spa/
├── frontend/   ← React + Vite
└── backend/    ← Backend API
```

## Frontend

### Tech stack

React, Vite, React Router, Axios, React Hook Form + Zod, Tailwind CSS, Recharts, Swiper, React Icons, Day.js
